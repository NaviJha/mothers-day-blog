# 🌸 Mother's Day Tribute Blog

A beautifully designed blog website to celebrate, honor, and share heartfelt stories about mothers. Built using **Next.js**, this project showcases articles, featured stories, and an elegant interface — perfect for Mother's Day or any tribute-oriented storytelling platform.

## 🔍 Project Overview

This blog lets users:
- Browse featured stories and personal tributes to mothers.
- Explore articles by category: **Stories**, **Health**, and **Inspiration**.
- Search articles by title or summary.
- View detailed article pages and story entries.
- Enjoy responsive design and optimized image loading.

🔗 [Visit the Live Site](https://mothers-day-blog-kappa.vercel.app)

## 🛠️ Getting Started Locally

### Prerequisites
Make sure you have these installed:
- **Node.js** (v16 or later)
- **npm** or **yarn**
- **Git**

### Installation Steps

1. **Clone the repository**
   
   git clone https://github.com/NaviJha/mothers-day-blog.git
   cd mothers-day-blog
Install dependencies
npm install

Run locally
npm run dev
